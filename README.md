# Featurewise

Featurewise is an open-source project for reviewing feature specifications in the AI application you already use, starting with Codex. It aims to find missing, ambiguous or contradictory decisions and suggest improvements backed by sources.

The project is for developers, tech leads, product managers, product owners and designers preparing work for implementation.

The planned product combines a review skill, Model Context Protocol (MCP) tools and a Console inside your AI application to inspect findings, evidence and decisions. AI analysis runs in that application. Basic reviews will work without a Featurewise account or Console.

## Current status

Documentation only: there is no installable plugin or verified runtime behavior yet. The current scope is the first skill experiment in Codex.

## Roadmap

1. **Skill and first plugin:** verifiable reviews, structured results and evaluation in Codex.
2. **MCP and Console:** integrated review and decision storage, immediately after the first verified skill.
3. **Indexing, retrieval and decision memory:** current sources and relevant decisions reused in later reviews.
4. **Consolidation:** reliability, compatibility with other hosts and collaboration.
